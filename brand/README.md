# Terminal Whimsy brand mark

The crest: a shield with a terminal prompt (`>_`). Gold rim, night-blue field, green prompt.

| File | Use it for |
|---|---|
| `terminal-whimsy-mark.svg` | The mark itself, full colour, transparent. Scales to any size. |
| `terminal-whimsy-mark-1024/512/256/128/64.png` | The same as PNG, for places that don't take SVG. |
| `terminal-whimsy-avatar.svg`, `-avatar-1024.png`, `-avatar-512.png` | Square icon on the night background: Discord server icon, social avatars. |
| `terminal-whimsy-lockup-dark.png` | Mark + name on the dark background: banners, headers. |
| `terminal-whimsy-lockup-transparent.png` | Mark + name with no background, for dark surfaces. |
| `terminal-whimsy-lockup-light.png` | Mark + name with dark lettering, for white surfaces. |
| `terminal-whimsy-mark-gold/white/black.svg` (+ `-1024.png`) | One-colour outline versions: watermarks, embroidery, single-colour printing. |

Colours: gold `#f2c56b`, night `#10131d` (field) / `#0a0c13` (background), terminal green `#7cf29a`.
Type: Cinzel 700 for the name, JetBrains Mono 600 for the `> GUILD · WOW FOREVER` line.
The lockup PNGs are rendered from `source/lockup-*.html` with headless Chrome.
