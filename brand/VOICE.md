# How the site talks

This covers the site's own words: headings, intros, buttons, the briefing. The wisp has its own rules in [WISP.md](WISP.md).

Write it the way a guildmate who has done the reading would post it in guild chat. Use "we" for the guild. Give the fact first, with the real number or date, and stop.

**Read it aloud.** If nobody in the guild would type it in Discord, rewrite it.

## Patterns that make it read as machine-written

| Avoid | Write instead |
|---|---|
| A colon and then a list of three: *"cheat sheet for WoW Forever: what changed, what to wear, and what Blizzard said."* | One plain point: *"What we've worked out about WoW Forever so far, so nobody turns up on 9 December with a Classic spec."* |
| Lists of three by habit | Name the one thing that matters, or two. |
| "Every", "everything", "all" when nobody counted | *"Official posts we've found"*, not *"Every official statement"*. |
| Taglines: "built for…", "lives in…", "one tap away", "the full story", "news that refreshes itself" | Say what it is: *"Headlines, pulled in a few times a day."* |
| Filler intros that only say "click here": *"Everything else is one tap away."* | Something useful: *"Pick your class on Changes and it hides whatever doesn't apply to you."* |
| "Not X, but Y" contrasts, em dashes, rhetorical questions in headings | Two short sentences. |
| Brochure words: seamless, comprehensive, ultimate, essential, dive in, your one-stop… | Plain words. |

Small jokes are fine when they're about the game or the guild (Classic specs, Leeroy, Onyxia's fire). Don't force one into every line.
